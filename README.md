# 🏢 BRIM AI — Conversational Assistant Platform

> **Refined Client Conversational Platform** with bespoke domain grounding, lead capturing, and seamless customer experiences.  
> **Visual & Design Direction**: Inspired by the creative, typography-driven, and warm aesthetic of **[BRIM](https://brim.co.in/)**.

---

## 🌟 Overview

**BRIM AI** is a client-centric conversational assistant platform. It enables businesses to manage domain-specific assistants that answer customer questions with verified project details, provide brochures, and capture qualified inquiries.

### Simplified Workflow
```
Client Login (saisrikar@example.com)
  ↓
BRIM AI Dashboard
  ↓
Create Assistant (3 Simple Steps: 01 Details → 02 Knowledge → 03 Review)
  ↓
Assistant Management Suite
  ├── Overview (Metrics, instructions, interactive test console)
  ├── Conversations (Customer transcripts & lead details)
  ├── Knowledge (Website pages & document sources)
  ├── Analytics (Inquiry trends & visitor feedback)
  ├── Share (Direct link, embed code, QR code)
  └── Settings (Appearance, instructions, notifications)
  ↓
Customer-Facing Assistant Preview (/chat/:botId)
```

## 🎨 BRIM Visual Design System

- **Warm Light Palette**:
  - Base: `#F7F3EC` (Warm ivory / cream)
  - Surface: `#FFFDF9` (Warm white)
  - Charcoal Typography: `#25221F`
  - Brand Accent: `#C85C4A` (Sophisticated warm terracotta)
  - Secondary Accent: `#C99A52` (Muted warm gold / ochre)
  - Accent Surface: `#F5EAE4`
- **Typography & Composition**:
  - Headings in `Plus Jakarta Sans`, UI text in `Inter`.
  - Editorial spacing, balanced hierarchy, and clean tactile cards.
- **Human-Centric Language**:
  - Focused on customer and business value rather than generic "AI" branding.

## 🛠️ Tech Stack & Local Setup

- **Framework**: React 18, Vite, React Router 6
- **Styling**: Vanilla CSS Design System (`variables.css`, `base.css`, `layout.css`, `components.css`, `chat.css`)
- **Icons**: Lucide React

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
